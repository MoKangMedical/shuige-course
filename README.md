# 水哥通识课

> 王昱珩（水哥）通识课程 · 10 节课 · 独行者的智慧

## 📖 课程简介

基于《最强大脑》「微观辨水」一战成名的 **王昱珩（水哥）** 的深度访谈与公开表达，系统提炼的 10 节通识课——观察力、独处、神经多样性、空间思维到人生哲学。

## 🎬 课程来源

纪录片研习社（114K 订阅）视频访谈：**「水哥自曝：我根本不需要朋友！」**

嘉宾：王昱珩（水哥）× 窦文涛 × 马未都 × 马家辉 × 周轶君

| 课时 | 标题 | 核心主题 |
|------|------|---------|
| 第1课 | 微观辨水——超强观察力的养成 | 观察力训练、520杯水挑战 |
| 第2课 | 清华往事——天才不需要合群 | 自闭症经历、清华美院时光 |
| 第3课 | 我不需要朋友——独处的力量 | 独处价值、反社交哲学 |
| 第4课 | 婚姻的真相——两个独立个体的契约 | 非传统婚姻观 |
| 第5课 | 自闭症到鬼才之眼——神经多样性的礼物 | 神经多样性、天赋转化 |
| 第6课 | 用眼睛破案——观察力如何改变现实 | 协助警方破案、现实应用 |
| 第7课 | 植物的智慧——从养动植物中学习生命 | 自然哲学、生命教育 |
| 第8课 | 人机大战——当最强人类大脑遇到AI | 人类 vs AI、智慧定义 |
